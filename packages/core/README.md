# @magi/core

Common TypeScript types shared across `@magi/*` packages.

## Exports

- `SystemId`
- `RiskLevel`
- `Severity`
- `MagiConfig`
- `MAGI_VERSION`

## Scripts

- `pnpm build` - build CJS, ESM, and declaration output with tsup
- `pnpm test` - run tests with Vitest
- `pnpm type-check` - run TypeScript without emitting files
- `pnpm lint` - run Biome checks
